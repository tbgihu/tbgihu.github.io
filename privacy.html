Privacy policy

Last updated: 19 November 2026

clip uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

Data accessed

With the owner's consent, the app uses the YouTube Data API to upload videos, set their titles and descriptions, read basic statistics (views, likes, comments) of the owner's own videos, and post or read comments on them.

Storage and sharing

The OAuth token is stored only on the owner's own computer. No Google user data is sold, shared with third parties, or used for advertising. The app does not access data of any other user.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
